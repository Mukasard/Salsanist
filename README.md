In dieser Bachelorarbeit wurde ein imperativer Salsa-Bot geschrieben, der mit einer generativen KI verglichen wird.
Dabei wurde versucht einen Algorithmus für die Musikrichtung Salsa zu entwickeln, der klaren Regeln der Musik folgt.
Der Prototyp wurde in Python mithilfe der Bibliothek music21 umgesetzt; AIVA ist die gewählte, konkurrierende KI.
